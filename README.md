# Avioni

Java desktop aplikacija (AWT) za rad sa aerodromima i letovima.

- unos i pregled aerodroma i letova
- prikaz aerodroma na mapi
- učitavanje i čuvanje podataka u CSV i JSON formatu
- tajmer neaktivnosti

## Pokretanje

Otvoriti projekat u IntelliJ IDEA i pokrenuti `src/Main.java`.
Primeri ulaznih fajlova su `test.csv` i `test.json`.
